# parthwebsite

Personal website for **Parth Ghumatkar**, built with [Next.js](https://nextjs.org), TypeScript, and Tailwind CSS.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- ESLint

## Getting started

Install dependencies (already done if you cloned the repo):

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Start dev server         |
| `npm run build`| Production build         |
| `npm run start`| Run production server    |
| `npm run lint` | Run ESLint               |

## Project structure

```
src/
  app/
    layout.tsx    # Root layout and metadata
    page.tsx      # Homepage
    globals.css   # Global styles
```

## Deploy

Deploy on [Vercel](https://vercel.com) or any platform that supports Next.js.
